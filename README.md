# Política de Privacidad de InmoLux 360

**Última actualización: 12 de Octubre de 2026**

Esta Política de Privacidad describe cómo KickApp ("nosotros") recopila, utiliza y protege tu información al usar la aplicación móvil y web InmoLux 360.

## 1. Datos que recopilamos
Para ofrecer nuestro servicio de visitas virtuales inmobiliarias, recopilamos los siguientes datos:
* **Dirección de correo electrónico:** Utilizada exclusivamente para crear tu cuenta de agente, autenticar tu acceso y gestionar tu suscripción.
* **Contenido de usuario:** Las fotografías panorámicas (360) e información de los inmuebles que decides subir a nuestros servidores de forma voluntaria.

## 2. Servicios de terceros integrados
InmoLux 360 utiliza infraestructura de terceros que cumple con los más altos estándares de seguridad y RGPD:
* **Google Firebase:** Para la autenticación segura de usuarios, bases de datos y almacenamiento de imágenes.
* **RevenueCat y Apple In-App Purchases:** Para procesar suscripciones de forma anónima y segura. Nosotros no almacenamos ni tenemos acceso a tus datos bancarios ni tarjetas de crédito.

## 3. Retención y Eliminación de Datos (Tus Derechos)
Como usuario, tienes control total sobre tus datos. Tienes derecho a solicitar la **eliminación permanente de tu cuenta** y de todos los datos asociados (tours e imágenes) en cualquier momento.
Para ejercer este derecho, puedes utilizar la opción "Eliminar Cuenta" dentro de la configuración de la aplicación o enviarnos un correo electrónico directo a: **kickappsur@gmail.com**.

## 4. Contacto
Si tienes dudas sobre esta política, contáctanos en: kickappsur@gmail.com
